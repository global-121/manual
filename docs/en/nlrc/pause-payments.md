title: Pause Payments
hide:
  - toc
---

As long as a registration has the status 'Included', they automatically receive a new payment each week. If needed, you can temporarily pause payments:

1. Find the registration(s)
2. Select the person(s) you want to pause assistance for
3. Click **Pause**
4. In the pop-up, write a reason under **Write a reason for the update**
5. Turn on **Send a message to registration(s)**
6. An automatic message will be sent in the preferred language
7. Click **Pause registration** (or **Pause registrations** if you selected more than one person)

You can also right-click on the registration in the list and select **Pause**
