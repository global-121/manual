!!! Important "Who can perform actions on this page ?"
    Users with **Organisational Admin rights** can create and duplicate programs. These rights do not depend on your role in a program: they are enabled by the 121 support team. If you cannot create new programs while you are required to do this, **please reach out to the 121 support team** so we can set this up for you.

### Create new program

Every time a new program starts, a user with Organisational Admin rights can create a program in the instance. After program creation, details can be changed at any time through the [Program Information](../settings/program-information.md) under Settings.

- On the left of your screen, open the **:material-menu: menu** and select **All Programs**.
- On the top right of the **All Programs Page**, click **:material-plus: Create new program**.

**Step 1**: Add a program name and an optional program description.

**Step 2**: Add general information to define your program details. You also decide if you wish to make use of "scope" and "validation" in this program. More information on scope and validation can be found on the [program information page](../settings/program-information.md).

**Step 3**: Specify the financial details, such as your currency, fixed transfer value and FSP(s).

![Create new program](../assets/img/settings-createnewprogram.gif)

!!! Note
    **Selecting your FSP in step 3 of program creation allows you to check which fields are required in your registration form** (in section Registration data). The configuration of the FSP by entering the credentials in the section FSP integration can be done at a later time, as long as this is before the first payment is made.

Upon completion of the 3 steps, you are directed to the [Program Settings](../settings/settings-overview.md) to finish your program creation. You can do this straight away or at a later time, as long as it is done before your program starts.

Navigate to the following pages for instructions:

- [Program information](../settings/program-information.md): edit your program and finance details, incl. your FSP(s).
- [FSP integration](../settings/fsp-integration.md): set up your FSP configuration and/or configure the manual option using Excel.
- [Registration data](../settings/registration-data.md): link your registration form to 121, and verify if the form includes the required fields for compatibility with 121 and the FSP(s).
- [Program team](../settings/programteam.md): set up your program team by adding users and assigning them a role (and scope).
- [Payment approval](../settings/payment-approval.md): set up your approval process for payments.

### Copy a program

You can also create a program by making **a copy of an existing program**. Only users with Organisational Admin rights see the **Duplicate** option.

- On the **All Programs** page, click the **:material-dots-horizontal: three dots** next to the program.
- Select **Duplicate**.
- Follow the **3 steps** and edit the details where needed.

The copy keeps the **FSP configurations**, **Approval thresholds** and **Program team** of the original program. After the 3 steps, link a registration form to complete the setup.

![Duplicate a program](../assets/img/settings-createprogramduplicate.png)
