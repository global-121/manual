The **Payment approval** is found in each of your active programs under **Settings** - **Users**. You can set up a different payment approval process per program.

!!! Important "Who can perform actions on this page ?"
    Program Admin can view, set up and update the payment approval process.

### Set up payment approval

On this page, you set up an approval process for program payments by selecting one or more users for each step. Only one user must approve in each step. Steps will run in order based on the amount conditions you set (from lowest to highest).

- Click on the **:octicons-pencil-24: pencil** on the top right;
- Select one or more users from your program team that must approve **all payments**;

![Payment approval](../assets/img/settings-paymentapproval1.png)

- If you wish to add user(s) to approve if the payment total exceeds a certain amount, select **:material-plus: Add approval step**, select the user(s) and add the minimum payment amount;
- If you wish to add user(s) to approve another minimum payment total, select again **:material-plus: Add approval step**, select the user(s) and add the amount;

![Payment approval](../assets/img/settings-paymentapproval2.png)

- **:material-check: Save** your changes.

!!! Note
    A real-life scenario of a payment approval process could be:

    - The Finance Manager must approve all payments. This user is set as the first approver.
    - The Secretary General or the DM Manager must approve all payments above 500,000 EUR. These users are set as second approvers with the same minimum threshold amount.

### Update payment approval

If you wish to update the payment approval process:

- Click on the **:octicons-pencil-24: pencil** on the top right;
- De-select users you want to remove from the approval step and select the user(s) you want to add;
- If you wish to remove the approval step as a whole, click :material-trash-can-outline:.

![Payment approval](../assets/img/settings-paymentapproval3.png)
