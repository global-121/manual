!!! Important "Qui peut effectuer des actions sur cette page ?"
    L'administrateur du programme peut effectuer des actions dans toutes les sections. Le responsable CVA peut modifier les informations sur le programme et consulter l'équipe du programme. Le responsable de l'équipe du programme peut gérer l'équipe du programme. [En savoir plus sur les rôles et permissions](../users/description-roles.md)

La page **Paramètres** vous permet de consulter et, si nécessaire, de mettre à jour votre programme. Il y a 5 sections :

- [Informations sur le programme](../settings/program-information.md) : les détails de base définissent la configuration et la structure de votre programme.
- [Intégration FSP](../settings/fsp-integration.md) : les PSF intégrés à votre programme, y compris l'option d'import/export manuel via Excel.
- [Données d'enregistrement](../settings/registration-data.md) : le formulaire d'enregistrement intégré au programme, la liste des champs requis pour 121 et vos PSF, et les champs utilisés pour trouver les enregistrements en doublon.
- [Équipe du programme](../settings/programteam.md), sous **Utilisateurs** : les utilisateurs de votre équipe de programme avec les rôles qui leur sont assignés.
- [Approbation du paiement](../settings/payment-approval.md), sous **Utilisateurs** : le processus d'approbation des paiements du programme.
