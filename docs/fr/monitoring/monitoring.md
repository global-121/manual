La page Suivi est un aperçu des détails de votre programme. Ceci inclut les principales métriques de votre aide monétaire et bons d'achat qui seront exécutés au sein de la plateforme 121. Ces métriques sont fournies par votre équipe lors de la création du programme dans l'instance et sont mises à jour et complétées avec le nombre de données importées dans le programme, comme le nombre d'enregistrements et les transferts traités à ce jour. Le tableau ci-dessous donne une description des métriques utilisées.

La page Suivi peut comporter un tableau de bord Power BI, soit la version de modèle 121, soit une version personnalisée, si vous l'avez demandée.

## Surveiller les mises à jour et les indicateurs de votre programme

- Entrez votre **programme**;
- Cliquez sur **Suivi** en haut de votre écran. Un aperçu de la configuration du programme et des dernières mises à jour vous sera alors présenté;

![Page Suivi](../assets/img/MonitoringPage.png)

Les métriques du programme traduisent vos exigences et paramètres de programme. Les détails fournissent l'information principale sur la durée et l'emplacement de votre programme, les fonds, les enregistrements ciblés et la prestation de l'aide monétaire. Chacun de vos programmes actifs peut afficher différentes métriques présentées dans le tableau ci-dessous. Ceux-ci peuvent être modifiés dans la page **Paramètres**.

| Type | Description |
| :----------------------------------- | :-------------------------------------------------------------------------- |
| **Description du programme** | Titre et description du programme. Par exemple, "Aide en espèces polyvalente" ou "Réponse conjointe" pour soutenir le traitement médical des familles touchées dans les zones éloignées. |
| **Date de début et de fin** | Information sur le début et la fin de votre programme d'aide en espèces |
| **Emplacement** | Pays ou région dans lequel le programme se déroule.​ |
| **Prestataires de services financiers (PSF)** | Nombre de PSF intégrés ou enregistrés dans votre instance et leurs noms |
| **Fonds disponibles** | Fonds initiaux définis pour être envoyés aux enregistrements pour cette distribution de programme. |
| **Durée** | Nombre de cycles de paiement qui seront émis pendant la durée du programme |
| **Valeur de transfert fixe** | La valeur fixe définie pour être transférée par enregistrement. Elle est multipliée par le multiplicateur de chaque enregistrement (le cas échéant). |
| **Aide en espèces versée** | Montant qui a été versé jusqu'à cette date. Ceci est calculé en fonction du nombre total d'enregistrements inclus dans les cycles de paiement, de la valeur de transfert fixe et du multiplicateur (le cas échéant). |
| **Personnes ciblées** | Nombre total d'enregistrements ciblés par ce programme |
| **Personnes enregistrées** | Nombre total d'enregistrements dans ce programme, sans les enregistrements déclinés et supprimés. |
| **Personnes incluses** | Enregistrements avec le statut inclus dans ce programme. |
| **Remaining funds** | Les fonds restants sont les Fonds disponibles - Aide en espèces versée. |

Le tableau est mis à jour automatiquement.

## En bas, vous pouvez voir les onglets : Tableau de bord, PowerBI, Modifications des données et Fichiers

- **Tableau de bord** fournit des mises à jour du programme en temps réel avec des indicateurs de base correspondants. [En savoir plus](./dashboard.md)
- **PowerBI** affiche un tableau de bord Power BI, une fois qu'il a été configuré pour votre programme. Il peut s'agir d'un tableau de bord modèle ou d'un tableau de bord personnalisé. [En savoir plus](powerbi.md)
- **Cartes de débit** est affiché uniquement pour les programmes qui utilisent des cartes de débit Intersolve Visa, et uniquement pour les utilisateurs à qui l'équipe d'assistance 121 a donné accès à la commande de cartes. Utilisez-le pour commander des cartes de débit et voir les cartes commandées. [En savoir plus](../payment/debit-cards.md)
- **Modifications des données** répertorie l'historique des modifications apportées aux enregistrements du programme. [En savoir plus](./data-changes.md)
- **Fichiers** est utilisé pour télécharger les fichiers utiles à votre programme. Cet onglet est affiché uniquement pour les utilisateurs autorisés à consulter les fichiers. [En savoir plus](./upload-files.md)
