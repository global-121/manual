!!! Note
    Pour des raisons de sécurité, si vous vous connectez avec votre adresse e-mail (avec un code à usage unique ou un mot de passe), vous êtes automatiquement déconnecté de la plateforme après 33 heures. Vous pouvez vous reconnecter de la même manière.

Vous pouvez vous connecter à la plateforme 121 en utilisant le lien fourni par e-mail ainsi que vos identifiants. Ce lien est spécifique à votre organisation et doit être utilisé chaque fois que vous vous connectez à la plateforme 121.

Vous pouvez vous connecter avec un **code à usage unique** envoyé à votre adresse e-mail, ou avec votre **mot de passe**.

### Comment se connecter avec un code à usage unique

- Accédez à la page de connexion.
- Entrez votre adresse e-mail dans la boîte « E-mail ». *Assurez-vous d'écrire votre adresse e-mail sans espaces supplémentaires.*
- Cliquez sur le bouton **Envoyer le code**.
- Consultez votre boîte de réception : vous recevez un e-mail avec l'objet « Your 121 Portal sign-in code ». *Si vous ne le trouvez pas, vérifiez votre dossier de courrier indésirable (spam).*
- Entrez le code de 6 caractères dans les cases « Saisissez votre code ». *Vous pouvez aussi copier-coller le code. Les majuscules et les minuscules sont acceptées.*
- Cliquez sur le bouton **Se connecter**.

Si vous avez saisi une mauvaise adresse e-mail, cliquez sur **Revenir à la page précédente** pour la modifier.

!!! Note "À propos du code à usage unique"
    - Le code est valable **10 minutes** et ne peut être utilisé qu'une seule fois. La page de connexion indique le temps restant.
    - Si le code a expiré ou si vous ne l'avez pas reçu, cliquez sur **Demander un nouveau code**. Vous pouvez demander un nouveau code une fois par minute. Seul le code le plus récent fonctionne.
    - Après 5 tentatives incorrectes, le code est bloqué. Vous pouvez demander un nouveau code après 15 minutes.
    - Si vous ne recevez pas de code, vérifiez que vous avez utilisé l'adresse e-mail de votre compte 121. Pour des raisons de sécurité, la page de connexion n'indique pas si un compte existe pour une adresse e-mail.

### Comment se connecter avec un mot de passe

Si vous **vous connectez pour la première fois**, vous aurez reçu vos identifiants de connexion par e-mail. **N'oubliez pas de modifier votre mot de passe la première fois que vous vous connectez**. Pour plus de détails sur la modification de votre mot de passe, consultez [cette page](../general/change-current-password.md).

- Accédez à la page de connexion.
- Cliquez sur **Se connecter avec un mot de passe**.
- Entrez votre adresse e-mail dans la boîte « E-mail ». *Assurez-vous d'écrire votre adresse e-mail sans espaces supplémentaires.*
- **Entrez le mot de passe qui a été partagé dans l'e-mail** dans la boîte « Mot de passe ». *Si vous souhaitez vérifier que vous avez écrit correctement votre mot de passe, vous pouvez cliquer sur l'icône de l'œil :material-eye:*
- Cliquez sur le bouton **Se connecter**.

Pour revenir à la connexion avec un code, cliquez sur **Se connecter avec un code à usage unique**.

### Authentification unique (SSO)

Si l'authentification unique (SSO) est activée dans le système de votre organisation, les utilisateurs devront se connecter en utilisant leur **adresse e-mail de compte Microsoft**. Cela les connectera automatiquement à la plateforme 121. Pour accéder à SSO, votre organisation doit l'avoir activé et votre e-mail doit figurer dans le registre.

Les utilisateurs SSO ne peuvent pas se connecter avec un code à usage unique.

---

!!! Question "Vous n'avez pas reçu vos identifiants de connexion ?"
    Vous pouvez demander à un utilisateur disposant des droits d'administrateur de l'organisation de vérifier si une invitation a été envoyée à votre e-mail et si votre compte utilisateur a été créé sur la plateforme 121 dans la [**page Utilisateurs**](../users/add-users.md).

    Si votre compte n'a pas encore été configuré, un utilisateur disposant des droits d'administrateur de l'organisation peut vous envoyer une invitation en [suivant les instructions de la page Ajouter des utilisateurs](../users/add-users.md).
