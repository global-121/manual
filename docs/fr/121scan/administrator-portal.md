Le Portail de l'administrateur de 121 Scan permet de configurer 121 Scan et de préparer votre distribution. Vous y trouverez quatre sections :

1. **Configurer le système** : ajouter et lier un programme 121 pour la distribution.
2. **Configuration des champs de vérification** : sélectionner les champs à afficher pendant la distribution afin que le personnel de distribution puisse vérifier l'identité du bénéficiaire lors du scan du code QR.
3. **Conception du bon** : personnaliser les bons de votre programme, par exemple en ajoutant le logo, le titre du programme et une description sur les bons.
4. **Générer les coupons** : une fois qu'un paiement a été créé dans la plateforme 121, générer automatiquement tous les bons et codes QR via cette section.

---

## Lier et configurer votre programme dans 121 Scan

Dans le Portail de l'administrateur, allez dans **Configurer le système** :

- Sélectionnez le programme dans la liste déroulante.
- Copiez l'URL du formulaire Kobo lié à votre programme.
- Sauvegardez.

**Comment trouver l'URL du formulaire Kobo :**

- Dans votre programme 121, allez dans **Paramètres > Données d'enregistrement**, cliquez sur le lien de configuration Kobo, puis copiez-le et collez-le.

<a id="configurer-les-champs-de-v%C3%A9rification"></a>

## Configurer les champs de vérification

Pendant la distribution, le personnel de distribution voit des données personnelles pour vérifier et confirmer l'identité du bénéficiaire. Votre programme peut contenir des informations spécifiques pour soutenir ce processus de vérification. Vous pouvez configurer l'écran d'affichage et les champs que verra le personnel de distribution dans la section **Configuration des champs de vérification**.

Sur cette page, vous pouvez également activer ou désactiver la photo.

- Sélectionnez le programme en haut de la page.
- Cliquez sur le champ de gauche et sélectionnez le champ à afficher dans la liste déroulante.
- Vous pouvez modifier le libellé dans différentes langues dans les champs à droite (2, 3, 4).
- Vous pouvez choisir si un champ est en lecture seule ou modifiable. Si vous choisissez modifiable, le personnel de distribution pourra modifier le champ pendant la distribution, et ce champ sera mis à jour dans la plateforme 121.
- Pour chaque nouveau champ, cliquez sur **+ Ajouter un nouveau champ**.
- Enfin, vous pouvez activer ou désactiver la photo.

!!! Note "Affichage de la photo : en ligne ou hors ligne"
    La photo ne peut être affichée sur l'écran du personnel de distribution que lorsqu'il est en ligne ; elle ne peut pas être affichée hors ligne. Si vous prévoyez que la distribution se déroule hors ligne, nous recommandons de ne pas activer la photo, mais d'ajouter des champs de vérification supplémentaires pour aider le personnel de distribution à identifier les bénéficiaires.

    Si vous prévoyez d'utiliser 121 Scan en ligne et de vous appuyer sur l'affichage de la photo, activez-la. Des champs de vérification complémentaires doivent tout de même être ajoutés pour compléter le processus de vérification, en plus de la photo et des informations personnelles du bénéficiaire.

## Concevoir et adapter les bons pour votre programme

Vous pouvez choisir un modèle de bon différent pour chaque distribution de programme.

- Allez dans **Conception du bon**.
- Sélectionnez le programme en haut de la page.
- Suivez le modèle et ajoutez le titre.
- Ajoutez une description et 1 ou 2 logos. Ces éléments sont facultatifs.
- Activez ou désactivez l'affichage d'un code QR.
- Vérifiez l'aperçu et sauvegardez.

Le modèle peut être mis à jour à tout moment. Si vous avez déjà imprimé les bons, vous devrez les réimprimer après la sauvegarde du nouveau modèle.

## Générer des bons avec ou sans code QR

Une fois qu'un paiement est créé dans la plateforme 121, vous pouvez exporter vos listes de paiement, ajuster le fichier Excel, et générer automatiquement le code QR dans la section **Générer les coupons** de 121 Scan.

!!! Note "Le générateur de bons est un convertisseur"
    Le générateur de bons convertit votre fichier Excel en PDF. Par conséquent, tous les champs de votre fichier Excel seront affichés sur les bons. Vous pouvez ajuster, supprimer ou ajouter des colonnes dans votre fichier Excel en conséquence. Le fichier Excel de paiement peut également être préformaté dans la plateforme 121, sous **Paramètres du programme > Configuration PSF**. Ces informations seront présentées sur les bons distribués au bénéficiaire.

Dans la plateforme 121 :

- Allez dans **Programme > Paiement > Page Paiements**.
- Exportez la liste de paiement du PSF.
- Vérifiez votre fichier Excel, et ajoutez ou supprimez les colonnes que vous souhaitez voir affichées sur les bons. Notez que l'ID de référence et le montant sont des colonnes par défaut et peuvent être supprimées manuellement.

Dans l'application 121 Scan :

- Allez dans **Portail de l'administrateur > Générer les coupons**.
- Sélectionnez le programme en haut de votre écran.
- Glissez-déposez votre liste de paiement du PSF.
- Cliquez sur **Importer les bons**.
- Cliquez sur **Générer le PDF**.
- Un fichier PDF est téléchargé. Vous pouvez ouvrir le fichier et vérifier les bons. Il est prêt à être imprimé.

## Comment lire les statuts de paiement dans la plateforme 121 après avoir utilisé 121 Scan

121 Scan est surtout utilisé pour les distributions en espèces, et la logique des statuts de paiement y est légèrement différente de celle des paiements numériques.

| Statut de paiement | Description | Actions requises |
| :--- | :--- | :--- |
| **EN ATTENTE** | Les bénéficiaires doivent encore recevoir leurs espèces ou les retirer auprès du PSF. Le statut reste en attente si la distribution n'a pas encore commencé, si les bénéficiaires n'ont pas encore retiré leurs espèces, ou si l'envoi de la réconciliation via 121 Scan n'a pas encore été effectué. Le statut reste également en attente si le personnel de distribution a scanné le code QR mais a sélectionné « Paiement refusé » parce que l'identité n'a pas pu être vérifiée — cela signifie que le bénéficiaire a peut-être reçu le mauvais code QR, et vous devrez peut-être convenir des prochaines étapes avec le personnel de distribution. | Si la distribution a commencé, cliquez sur **Send (Envoyer)** pour mettre à jour les statuts de paiement. Si le statut reste en attente après l'envoi et la fin de la distribution, les bénéficiaires n'ont pas encore retiré leurs espèces. Vous voudrez peut-être faire un suivi avec le personnel de distribution ou directement avec les bénéficiaires. |
| **RÉUSSI** | Les bénéficiaires ont retiré leurs espèces ; le code QR a été scanné, et le personnel de distribution a envoyé la réconciliation de paiement via 121 Scan. | Aucune action requise. |
| **ÉCHOUÉ** | Ce statut n'est pas utilisé. Comme 121 Scan est utilisé pour des distributions physiques ou en espèces, il est peu probable qu'une distribution échoue — elle est soit retirée, soit toujours en attente. | Aucune action requise. |
