## Utiliser 121 Scan pour la mise à jour des statuts de paiement et la réconciliation

121 Scan permet de réconcilier les paiements en espèces et de mettre à jour les statuts de paiement dans la plateforme 121.

- Connectez-vous à 121 Scan en tant que « Personnel de distribution ».
- Sélectionnez le programme.
- Cliquez sur **Sync (Synchroniser)**. Cela synchronisera tous les paiements en attente de votre programme. Attendez que la synchronisation soit terminée : elle affiche alors le nombre total de paiements attendus. N'actualisez pas la page avant que le petit cercle ait fini de tourner.
- Cliquez sur **Scan (Scanner)**. Vous pouvez désormais passer hors ligne ou rester en ligne. Utilisez la caméra pour scanner le code QR, ou saisissez le code à 8 chiffres dans le champ ci-dessous.
- Confirmez les informations du bénéficiaire affichées à l'écran. Si l'identité est confirmée, appuyez sur **Paiement approuvé**. Si l'identité ne peut pas être vérifiée, appuyez sur **Paiement refusé**.
- Passez au scan suivant jusqu'à ce que la distribution soit terminée.
- Cliquez sur **Send (Envoyer)**. Cela réconciliera tous les paiements en attente dans 121 Scan et mettra à jour les statuts en conséquence.

**Envoyez les données du jour dès la fin d'une distribution** — attendre risque de les faire perdre si l'appareil est perdu, changé ou réinitialisé.

---

## Qui peut utiliser 121 Scan&nbsp;?

### Personnel et volontaires de la Croix-Rouge

Lors d'une distribution en espèces, 121 Scan facilite les phases de vérification et de réconciliation des bénéficiaires. Le personnel de la Croix-Rouge et du PSF n'a ainsi pas besoin de comparer manuellement une liste papier ou un tableau avec 121 par la suite, bien qu'un processus de réconciliation clair et convenu avec le PSF reste nécessaire, en particulier pour les cas où un code ne peut pas être retrouvé ou un paiement est rejeté.

### Agents PSF

Les agents PSF peuvent utiliser 121 Scan pour faciliter les phases de vérification et de réconciliation des bénéficiaires. Cela permet à l'équipe du programme de la Croix-Rouge d'obtenir les mises à jour de paiement bien plus rapidement, tout en évitant les échanges de données par différents e-mails et tableaux Excel. Le PSF est responsable de l'enregistrement précis des résultats de paiement et de leur envoi rapide vers 121. C'est pourquoi un processus de réconciliation convenu avec le PSF, ainsi qu'un accès internet fiable pour synchroniser, sont tous deux nécessaires pour utiliser 121 Scan.

## Autoriser l'accès à la caméra sur votre appareil

121 Scan a besoin de votre caméra pour scanner les codes QR. Généralement, votre appareil le demande automatiquement la première fois ; appuyez sur **Autoriser**. Si l'accès a été bloqué auparavant :

- **Android :** Paramètres > Applications > [votre navigateur] > Autorisations > Caméra > Autoriser, puis rechargez la page. (Les noms de menus varient selon la marque du téléphone.)
- **iOS :** Réglages > [votre navigateur, par ex. Safari] > Appareil photo > Autoriser, puis rechargez la page.

## Résolution des problèmes avec 121 Scan

### Internet, Wi-Fi, données mobiles ou satellite

- Internet n'est nécessaire que pour **Sync (Synchroniser)** et **Send (Envoyer)**, pas pour scanner. Une brève coupure de signal n'interrompra pas votre travail (121 Scan attend 3 échecs de vérification avant de passer hors ligne).
- Si **Sync (Synchroniser)** ou **Send (Envoyer)** ne se termine pas, vérifiez votre connexion, déplacez-vous vers un meilleur signal, et réessayez ; gardez l'onglet du navigateur ouvert toute la journée.
- Une liste longue et riche en photos prend plus de temps à synchroniser et utilise plus de données ; faites-le donc sur une connexion stable.
- Si vous utilisez Starlink, nous recommandons de passer aux données mobiles ou au Wi-Fi et de réessayer.

### Problèmes de caméra ou de scan

- La caméra ne s'ouvre pas : vérifiez l'autorisation (voir [**Autoriser l'accès à la caméra**](#autoriser-lacc%C3%A8s-%C3%A0-la-cam%C3%A9ra-sur-votre-appareil) ci-dessus).
- Le code QR ne se scanne pas : vérifiez qu'il n'est pas endommagé ou sale ; sinon, saisissez son numéro de référence.
- « Code QR invalide » : cela signifie généralement qu'il a déjà été utilisé ; si un code réellement nouveau échoue, orientez la personne vers votre point focal IM/CVA.
- Rien ne correspond : vérifiez que le bon programme a été sélectionné, et que le paiement n'a pas plus de 14 jours (la fenêtre de **Sync (Synchroniser)**) ; sinon, vérifiez avec votre point focal.

### Problèmes d'appareil ou de page

- La page est figée ou ne se charge pas : rechargez ou redémarrez l'appareil, puis rechargez à nouveau.
- Déconnecté ou désynchronisé : reconnectez-vous et relancez **Sync (Synchroniser)**.

Nous recommandons de fermer tous les onglets et applications si votre appareil a du mal à télécharger les données dans 121 Scan, puis de réessayer.

## Le code QR ne peut pas être scanné, ou un message d'erreur apparaît

**Le code QR ne peut pas être scanné :**

- Le code QR est endommagé, flou, ou l'impression n'est pas nette.
- Le code QR peut être remplacé ou réimprimé avec une meilleure qualité.
- Vous pouvez aussi utiliser le code à 8 chiffres situé sous le code QR imprimé et le saisir dans le champ prévu.

**Message d'erreur : le code QR est incorrect ou introuvable.**

- **Avez-vous synchronisé le paiement avant de commencer à scanner ?** Si non, votre appareil ne peut peut-être pas encore trouver le paiement, car vous devez d'abord synchroniser les paiements en attente.
- **Avez-vous scanné le même code QR plusieurs fois et distribué les espèces ?** Si aucun autre paiement en attente n'est lié à ce code QR, vous ne pourrez plus le scanner.
- **Aucune de ces explications ne s'applique ?** Contactez l'administrateur du programme et vérifiez le statut du bénéficiaire.

## Intégration et assistance

121 Scan est en développement actif et n'est actuellement utilisé que dans un nombre limité de contextes pilotes. Si vous avez des questions sur la pertinence de 121 Scan pour votre programme, ou si vous avez besoin d'aide pour l'utiliser, contactez [**support@121.global**](mailto:support@121.global).
