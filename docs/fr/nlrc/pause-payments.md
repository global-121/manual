title: Suspendre les paiements
hide:
  - toc
---

Tant qu'un enregistrement a le statut « Inclus(e) », il reçoit automatiquement un nouveau paiement chaque semaine. Si nécessaire, vous pouvez mettre les paiements en pause temporairement :

1. Trouvez l'enregistrement (les enregistrements)
2. Sélectionnez la (les) personne(s) pour lesquelles vous souhaitez mettre l'assistance en pause
3. Cliquez sur **Pause**
4. Dans la fenêtre contextuelle, indiquez une raison sous **Indiquer la raison de la mise à jour**
5. Activez **Envoyer un message aux enregistré(e)s**
6. Un message automatique sera envoyé dans la langue préférée
7. Cliquez sur **Mettre en pause l'enregistrement** (ou **Mettre en pause les enregistrements** si vous avez sélectionné plusieurs personnes)

Vous pouvez également cliquer avec le bouton droit sur l'enregistrement dans la liste et sélectionner **Pause**
