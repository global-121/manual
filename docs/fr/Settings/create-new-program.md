!!! Important "Qui peut effectuer des actions sur cette page ?"
    L'administrateur du programme peut créer un programme. Cela nécessite les **droits d'administrateur de l'organisation**, activés par l'équipe d'assistance 121. Si vous êtes administrateur de programme et que vous ne parvenez pas à créer de nouveaux programmes alors que cela est requis pour votre rôle, **veuillez contacter l'équipe d'assistance 121** afin que nous puissions configurer cela pour vous.

### Créer un nouveau programme

Chaque fois qu'un nouveau programme commence, l'administrateur du programme peut créer un programme dans l'instance. Après la création du programme, les détails peuvent être modifiés à tout moment via la page [Informations sur le programme](../Settings/program-information.md) sous Paramètres.

- Dans le menu de gauche de l'écran, ouvrez le **:material-menu: menu** et sélectionnez **Tous les programmes**.
- En haut à droite de la page **Tous les programmes**, cliquez sur **:material-plus: Créer un nouveau programme**.

**Étape 1** : Ajoutez un nom de programme et une description de programme facultative.

**Étape 2** : Ajoutez des informations générales pour définir les détails de votre programme. Vous pouvez également décider si vous souhaitez utiliser la **portée** et la **validation** dans ce programme. Plus d'informations sur la portée et la validation sont disponibles [ici](../Settings/program-information.md).

**Étape 3** : Spécifiez les détails financiers, tels que votre devise, la valeur de transfert fixe et le(s) PSF.

![Créer un nouveau programme](../assets/img/settings-createnewprogram.gif)

!!! Note
    **Sélectionner votre PSF à l'étape 3 de la création du programme vous permet de vérifier les champs requis dans votre formulaire d'enregistrement** (dans la section Données d'enregistrement). La configuration du PSF en saisissant les identifiants dans la section Configuration PSF peut être effectuée ultérieurement, tant que cela est fait avant le premier paiement.

Une fois les 3 étapes terminées, vous accédez à la page [Aperçu des paramètres](../Settings/settings-overview.md) pour finaliser la création de votre programme. Vous pouvez le faire immédiatement ou plus tard, tant que cela est fait avant le début de votre programme.

Accédez aux pages suivantes pour obtenir des instructions :

- [Informations sur le programme](../Settings/program-information.md) : modifiez les détails de votre programme et vos informations financières, y compris votre ou vos PSF.
- [Configuration PSF](../Settings/fsp-integration.md) : configurez votre PSF et/ou l'option manuelle via Excel.
- [Données d'enregistrement](../Settings/registration-data.md) : liez votre formulaire d'enregistrement à 121 et vérifiez que le formulaire contient les champs requis pour 121 et le(s) PSF.
- [Équipe du programme](../Settings/programteam.md) : configurez votre équipe de programme en ajoutant des utilisateurs et en leur attribuant un rôle (et une portée).
- [Approbation des paiements](../Settings/payment-approval.md) : configurez votre processus d'approbation des paiements.

---

### Copier un programme

Vous pouvez également créer un programme en utilisant **une copie d'un programme existant** :

- Sur la page **Tous les programmes**, cliquez sur les **trois points :material-dots-horizontal:** à côté du programme.
- Sélectionnez **Dupliquer**.
- Suivez les **3 étapes** et modifiez les détails si nécessaire.
