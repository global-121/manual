1. Allez à la page **Enregistrements** en haut. Vous verrez le tableau d'enregistrement.
2. Il existe deux façons de trouver un enregistrement:
    - Recherche rapide
    - Filtrage par colonne

## Recherche rapide

Pour utiliser la recherche rapide, cliquez sur l'icône de recherche (:octicons-search-16:) en haut à droite du tableau. Vous pouvez maintenant rechercher dans la plupart des colonnes.

!!! Info
    La recherche rapide fonctionne pour la plupart, mais **pas** toutes les colonnes. Si vous ne trouvez pas ce que vous cherchez, utilisez le filtrage par colonne.

## Filtrage par colonne

Vous pouvez filtrer chaque colonne du tableau en cliquant sur l'icône de filtre (:material-filter-outline:) à côté de l'en-tête de colonne.

## Recherche par numéro de téléphone depuis un outil d'assistance

Votre organisation peut relier un outil d'assistance (helpdesk) au portail 121. Lorsque vous recevez une tâche dans cet outil, il peut ouvrir le portail 121 sur une page de recherche pour le numéro de téléphone de l'appelant. Cette page affiche les enregistrements qui ont ce numéro de téléphone ou ce numéro WhatsApp, dans les programmes et le périmètre auxquels vous avez accès :

- Si un seul enregistrement est trouvé, son profil d'enregistrement s'ouvre directement ;
- Si plusieurs enregistrements sont trouvés, une bannière indique combien ont été trouvés avec ce numéro. Cliquez sur un onglet (nom de l'enregistrement et programme) pour ouvrir chaque enregistrement ;
- Si rien n'est trouvé, un message indique qu'aucune information n'a été trouvée dans les programmes auxquels vous avez accès.
